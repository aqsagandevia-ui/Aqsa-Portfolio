# Aqsa Gandevia – Developer Portfolio

A modern, responsive developer portfolio built with **React** and **Vite**. It showcases my skills, projects, education, and contact information.

## Live Demo

[Portfolio] (https://aqsa-portfolio-vq33.vercel.app/)

## Features

- Responsive portfolio layout
- About, skills, projects, and education sections
- Project details page
- Light and dark theme
- Contact section
- Resume download
- Backend API integration

## Tech Stack

**Frontend**
- React
- Vite
- JavaScript
- HTML and CSS

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose

**Tools**
- Git and GitHub
- Vercel

## Getting Started

### Prerequisites

- Node.js and npm
- MongoDB

### 1. Clone the repository

```bash
git clone https://github.com/aqsagandevia-ui/Aqsa-Portfolio/
cd Aqsa-Portfolio
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Run the frontend

```bash
npm run dev
```

### 4. Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 5. Run the backend

```bash
npm run dev
```
